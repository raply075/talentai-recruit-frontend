# 📖 Overview

TalentAI Recruit is an AI-powered career platform that helps users improve their job application process through intelligent automation.

The application provides an elegant dashboard where users can:

- 📄 Upload and analyze resumes
- 🤖 Generate AI-powered cover letters
- 💬 Practice interview questions
- 📊 View ATS score and resume insights
- 👤 Manage professional profile
- 🖼 Upload profile photo
- 🔒 Secure account management

The frontend communicates with a Laravel REST API and is designed with a modern SaaS user experience.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/raply075/talentai-recruit-frontend.git
```

```bash
cd talentai-recruit-frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Environment Variables

Create `.env`

```env
VITE_API_URL=http://localhost:8000/api
```

---

## Run Development Server

```bash
npm run dev
```

Application will run on

```
http://localhost:5173
```

---

## Build Production

```bash
npm run build
```

---

## Preview Production

```bash
npm run preview
```
